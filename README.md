# 🧮 Virtual Calculator in C

A modern desktop virtual calculator built using **C programming language and GTK4**.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Decimal numbers
- % Percentage
- ± Positive/Negative toggle
- ⌫ Backspace
- 🧹 Clear (AC)
- ⌨️ Keyboard support
- 🎨 Dark-themed graphical interface
- ⚠️ Division-by-zero error handling

## 🛠️ Technologies Used

- C
- GTK4
- GCC
- MSYS2
- VS Code

## 💻 Platform

Windows
